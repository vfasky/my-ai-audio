FoloToy AI Passport

挂在胸前的
随身麦克风

开源可穿戴的 AI 工牌是 go-voice 的随身收音设备：内置 ES8311 音频编解码器，通过蓝牙把语音实时传给 Mac，屏幕显示连接与收音状态。

  • UP开始 / 结束说话
  • DOWN发送回车
  • OK删除或取消，长按清空

工牌需运行 Go Voice 固件，可在 go-voice 的“固件安装”页通过 USB 写入。应用会对照设备与随附版本，旧固件会提示更新；设备身份与永久 Recovery 保持不变。

三步，从声音到文字

  1. 01

    按键说话

    按下工牌 UP 键，或单独按住 Shift+Option 使用 Mac 麦克风，go-voice 记住你当前所在的应用。

  2. 02

    识别与纠正

    默认由 Apple 在本机识别，也可选择在线引擎；按词库、词边界与替换规则纠正专有名词。

  3. 03

    插入光标

    可选 AI 润色去掉语气词、修正标点，然后直接插入目标应用。

为听写而生的细节

原生 macOS 菜单栏应用，基于 MyGo 构建，界面固定暗色。

本机或在线识别

默认使用 Apple SpeechAnalyzer 本机识别；可选支付宝 MaaS、阿里云百炼 Omni Realtime 或火山引擎豆包流式识别。同一服务商的模型共用一个 API key，切换模型不用重填；Omni 与豆包通过 WebSocket 实时上传，说话时即可看到文字。

悬浮听写胶囊

屏幕底部的胶囊显示识别文字，可随时取消，或在润色期间直接插入识别原文。

公共词库与个人专名

通用词库与 IT 包默认开启，为纠错提供候选；个人专名独立保留。显式替换规则在本地直接生效，支持个人词库 JSON 导入导出。

AI 润色

Apple 本地模型或 OpenAI 兼容接口，提供专名、轻度、结构化模式；结构化像校对者一样结合上下文纠正识别错误，可指定网关供应商；失败时保留识别原文。

USB 固件安装

签名应用内置固件，写入前逐项预检，只写应用分区。固件页显示设备与随附版本，旧固件会提示更新。

常驻菜单栏 · 自动更新

可登录时启动；正式版经过签名与公证，每天检查一次 Ed25519 签名更新。

个人专名与替换规则

留住你的用语

公司名、产品名、人名和新术语单独管理。首次没有词库文件时，内置 16 个默认词条和 15 条替换规则；已有词库保持原样。纠错检索完整个人词库，已正确写出的个人词条继续受保护。

支持 JSON 导入导出 · 显式替换本地生效

在哪里管理打开“词库 → 公共词库”，可分别开关通用库和 IT 包，保存后从下一次语音生效。

怎样参与纠错公共词库需要开启 AI 润色或 Jev，结合上下文比较候选和原文；命中词条不会直接强制替换。两者关闭时，显式替换规则仍可使用。

词库留在本机数据随应用提供，本地检索，不占用个人识别提示名额。开启远端润色或 Jev 时，只发送相关候选与所需上下文，不发送完整公共词库。

你的声音，留在你手里

默认全部在本机完成。任何云端处理都需要你明确选择。

  • 按需使用麦克风工牌音频通过蓝牙接收；Mac 麦克风仅在按住热键时录音，首次使用需单独授权，可在“通用”页更换或关闭热键。
  • 不保存音频音频只在内存中处理，不保存、不回放，也不保留转写历史。
  • 密钥只存钥匙串API key 仅存入 macOS 钥匙串，不写入设置文件或日志；各在线服务商的凭据分开保存，已保存的 key 会在输入框中提示。
  • 不悄悄上云识别失败时结束本次语音；润色失败时保留识别原文。不会自动切换到云端。
  • 云端功能透明可控选择在线识别时，音频发送到所选服务；选择远端润色或开启 Jev 时，发送转写文字、相关词库提示与候选等上下文。润色与 Jev 不接收音频，也不接收完整公共词库。
