# go-voice 发布说明

每个 `## <版本>` 小节是一次已签名 `go-voice` 发布的说明。`scripts/release.sh` 要求两个语言文件都有该小节；应用界面为中文，因此简体中文小节会签入更新 manifest，并显示在应用内更新窗口。只写用户可感知的变化，两种语言保持一致。参见[更新与发布](updates.zh_CN.md)。

## 0.7.1

- 尚无词库文件时，使用随应用提供的 16 个默认词条与 15 条替换规则开始使用，涵盖公司名、产品名、工作术语及常见误识别，可在“词库”页管理。已有词库文件保持原样；升级不会添加、替换或删除其中的内容。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。随附固件仍为 0.2.0。在“词库”页管理词条和替换规则。构建与配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.7.1/gui/README.zh_CN.md)。默认词库加载已通过主机测试；首次启动界面、实际识别效果和已安装应用升级后的权限保留仍待验证。

## 0.7.0

- 修复受支持五分区设备安装 USB 固件时被 `RECOVERY_MARKER_MISSING` 拦截的问题。两种受支持布局现使用相同的有界 USB ROM 应用写入流程，保留镜像、芯片、安全状态、Flash 容量与分区检查、设备端校验和复位；bootloader、设备身份、资源和 Recovery 存储保持原样。已使用随包安装助手在五分区设备完成真实安装。
- 在 macOS 任意位置单独按住 Shift+Option，即可使用 Mac 麦克风听写；松开后按所选引擎、词库和润色设置识别并插入。在“通用”页可更换组合键或关闭；按住期间按下其他键会取消录音，原有修饰键快捷键仍可使用。麦克风为可选权限，首次使用时申请；选择在线识别时，这段音频会发送给所选服务商。
- 升级应用框架与更新器。正式版在启动约十秒后及每天检查更新，暂存已校验的更新，等待应用退出后替换，再通过 LaunchServices 启动。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。随附固件仍为 0.2.0。在“通用”页设置麦克风热键，或在“固件安装”页通过 USB 安装固件。构建与配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.7.0/gui/README.zh_CN.md)。麦克风与热键的实际授权、已安装应用升级后的权限保留、九分区 USB 写入和中断写入恢复仍待验证。

## 0.6.2

## 0.6.1

- 修复 macOS 编译目标：0.6.0 声明支持 macOS 26，主程序实际却要求 macOS 27。现在主程序及其 C/C++ 依赖均以 macOS 26 为最低目标编译、链接。

在 macOS 26 及以上的 Apple 芯片 Mac 上安装 DMG，并替换“应用程序”中的旧版 go-voice。随附固件仍为 0.2.0。构建与配置步骤见[应用指南](../README.zh_CN.md)。macOS 26 真机上的安装、权限与蓝牙听写仍待验证。

## 0.6.0

- 新增火山引擎豆包流式语音识别作为在线引擎，提供小时版和并发版两种资源。说话时显示实时文字，以标记为最后一包的回复作为最终转写。API key 使用独立钥匙串账号，“测试连接”只发送静音，失败会结束本次语音，不会自动切换引擎。选用后每次语音的音频会发送到火山引擎，不发送词库。
- 结构化润色改为校对者身份：结合上下文和常识纠正识别错误，不再局限于词库与候选，包括与句子不搭的真实词语；说错重来时只保留最终说法；先理顺不通顺的语句，再分段或列项。仍然拒绝摘要、回答和编造内容。关闭、专名、轻度模式不变。
- API key 已保存时给出提示：润色、语音识别和 Jev 页的 key 输入框留空时，会说明钥匙串中已有 key，留空即沿用。语音识别下拉框每个服务商只列一项，其模型在服务商卡片内选择并共用一个 key，切换模型不再要求重新填写。状态胶囊和设备页会显示所选在线识别服务商的名称。
- 为 OpenAI 兼容润色端点新增两个选项：供应商路由（仅允许、优先顺序、排除三个列表，以及不允许其他供应商的开关），作为顶层 provider 对象发送，供蚂蚁数科 DTMaaS 等网关使用；以及“流式输出”开关，用于只接受流式请求的服务或模型。流式不会更快，润色结果仍在校验后整体插入。
- 阿里云百炼 Omni Realtime 默认模型改为 qwen3.8-omni-flash-realtime，自由填写的端点改为地域（北京或新加坡）加工作空间 ID；“自定义”仍可填写完整 WSS 地址。已有 Omni 用户需要填写一次工作空间 ID，已保存的模型名保持不变。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。随附固件仍为 0.2.0。构建与配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.6.0/gui/README.zh_CN.md)。豆包真实服务、DTMaaS 供应商路由的真实效果、结构化润色在各模型上的质量、已安装版本更新后的权限保留以及实体设备验收仍未验证。

## 0.5.0

- 内置 96,336 词通用中文词库和 12,854 词 IT 行业包，默认全部开启。在“词库 → 公共词库”管理，保存后从下一次语音生效；两套词库去重后共 108,623 个词。
- 纠错检索完整个人词库与替换目标，Top 100 识别提示之外的词条也能参与。公共词库与个人词条分开，不占用识别提示名额。
- 结合来源信息比较公共候选、个人专名和原文。已正确写出的个人词条继续受保护，公共词频不会直接触发替换。公共词库需要开启 AI 润色或 Jev；两者关闭时，显式替换规则仍然生效。
- 使用随应用提供并缓存的词库在本地检索，只把本句命中的候选交给已启用的远端模型，不发送完整公共词库。候选或上下文超限而无法完整判断时保留原文。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。进入“词库 → 公共词库”管理默认开启的通用库和 IT 包。随附固件仍为 0.2.0。构建与配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.5.0/gui/README.zh_CN.md)。真实听写纠错效果、已安装应用升级后的授权保留及实机验收仍待验证。

## 0.4.0

- 固件安装页显示设备与随附固件版本；已连接设备低于应用随附版本时提示更新，并在侧栏显示「更新」。随附固件现为 0.2.0。
- 词库与替换规则改为按本地词边界纠正：去重后的替换目标会补齐 Top 100；最终纠正按完整词匹配已配置的中文原词，不跨标点，关闭 AI 润色和 Jev 时也生效。实时预览仍按字面规则替换。
- 改进 Jev 词库判断：结合完整转写和本地分词，将每处重叠的同音候选与保留原文比较，只有达到 70% 才直接替换或保护原文。请求发送完整转写、分词和命中的候选词，不发送音频和无关词库；过长时跳过。真实模型效果仍待验证。
- 随附固件降低待机功耗：熄屏后按键扫描变慢，麦克风空闲 5 秒后关闭模拟通路，屏幕随背光休眠。熄屏后第一次按键最多多约 50 ms。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。连接工牌后可在固件页核对版本并按提示安装 0.2.0。构建与配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.4.0/gui/README.zh_CN.md)。真实 Jev 效果、实机词边界纠正、待机电流和真机固件更新仍待验证。

## 0.3.0

- “语音识别”页新增阿里云百炼 Omni Realtime WebSocket，可填写端点、模型与 API key；录音时实时上传，松开按键后提交，只插入输入语音的转写结果，凭据与支付宝 MaaS 分开保存。
- 本地构建命名为 `go-voice-debug`，主应用和所有 helper 使用独立的 macOS 权限身份，避免开发版覆盖正式版的权限记录。
- 在仓库根目录使用 `bun run dev` 启动带签名的 watch 调试会话；Go 源码与配置变化后自动重构建并重启调试应用。
- [产品网站](https://go-voice.yzsaas.net/)提供最新 Apple 芯片版下载、使用说明及历史更新日志。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。在“语音识别”页选择阿里云百炼 Omni Realtime，填写与端点和模型匹配的 API key。构建与配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.3.0/gui/README.zh_CN.md)。真实 Omni 识别、设备听写及已安装应用升级后的授权保留仍待验证。

## 0.2.0

- 新增“语音识别”页面，可选在线识别：支付宝百灵 MaaS 的 Fun-ASR、Paraformer v2 边说边返回文字，Qwen3-ASR-Flash 在松开按键后识别整段录音。默认仍使用 Apple 本地识别。在线识别会将本次语音发送至支付宝百灵 MaaS，API 密钥保存在钥匙串中，失败时说明原因，不切换引擎。
- 悬浮胶囊实时显示识别文字，新文字从右侧滑入，Apple 本地识别现在约每秒更新一次。预览气泡在 AI 润色时出现，方便直接插入识别原文。
- 词库页面可选启用 Jev，在润色前判断中文同音词纠正，关闭 AI 润色时也可生效。支持 TypeSafe 和支付宝百灵 MaaS 等兼容 System One 的服务。只发送匹配片段、周边上下文和候选词条，API 密钥保存在钥匙串中。默认关闭，超过四秒或失败时跳过。
- 新增“通用”页面的“登录时启动”开关。登录后 go-voice 常驻菜单栏，仅在缺少必需权限时打开权限引导；开关同步 macOS 登录项设置。

在 macOS 26 及以上系统安装 Apple 芯片版 DMG，或在已安装的正式版中选择“检查更新…”。配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.2.0/gui/README.zh_CN.md)，构建与签名方法见[发布指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.2.0/gui/docs/updates.zh_CN.md)。本版本尚未验证实机听写、真实在线服务的识别质量、登录项行为及已安装应用的更新流程。

## 0.1.0

- go-voice 首个签名并公证的版本，适用于 macOS 26 及以上的 Apple 芯片 Mac。
- 通过蓝牙接收所选 FoloToy AI Passport 的语音，在本机转写、可选 AI 润色，并插入到听写时所在的应用。悬浮胶囊实时预览文字，支持取消或直接插入。
- 管理词条和本地替换规则，并将它们一起导入、导出为 JSON。关闭 AI 润色时，替换规则仍然生效。
- 可选 Apple FoundationModels 或 OpenAI 兼容润色引擎，支持 Chat Completions 和 Responses。优先按词库纠正专有名词，轻度润色去除无意义语气词，并可在保存前测试远端连接。
- 按权限引导完成设置，通过 USB 安装内置应用固件，同时保留设备身份和永久 Recovery。
- 菜单栏“检查更新…”现在可以安装已签名的更新；正式版也会每天自动检查一次。

下载 Apple 芯片版 DMG，将 go-voice 拖入“应用程序”，打开后完成权限引导，再选择你的 FoloToy AI Passport。配置步骤见[应用指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.1.0/gui/README.zh_CN.md)，构建与签名方法见[发布指南](https://github.com/vfasky/my-ai-audio/blob/go-voice-v0.1.0/gui/docs/updates.zh_CN.md)。
